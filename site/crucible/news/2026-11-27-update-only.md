title: Update only from RadioFoundry
---
Crucible now updates only radios that already run RadioFoundry or Crucible. The installer for radios with the
manufacturer's firmware is gone from this page.

To start, install RadioFoundry from [radiofoundry.org](https://radiofoundry.org/flash/index.html) and get the radio
working with it. Then update to Crucible here.

Use Crucible only if you accept opinionated features that are sometimes not tested. Crucible brings in RadioFoundry's
changes. When a Crucible feature conflicts with RadioFoundry, or RadioFoundry solves the problem better, Crucible
removes its own feature.

To go back to RadioFoundry, install it again and reset the settings.
