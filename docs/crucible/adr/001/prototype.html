  3. 3Save your channels

    Save your channels in a file before the install. Crucible changes the channel memory of the radio.

    1. Set the radio to ON.
    2. Connect the radio to the computer with the programming cable.
    3. Open the CPS.
    4. In the CPS, click Read. The CPS copies the channels from the radio.
    5. Save the file on your computer.
    I do not have the CPS
